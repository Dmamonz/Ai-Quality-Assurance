# Ai-Quality-Assurance
Script Program Python Ai QA for checking code smells 


API KEY BUATAN UNTUK OPENROUTER (Buat API key di website openrouter dan pakai model gemini 2.5 flash untuk sistem LLM)

1. Untuk mencoba, silahkan buat structur folder project berisi folder src dan test yang didalamnya ada skript project python. 
2. Selanjutnya, masukkan code Ai_Quality Assurance ini kedalam folder project, diluar folder src dan test.
3. Cari baris code API key dan masukkan API key dari website openrouter yang menggunakan akses LLM Gemini 2.5 flash kedalam tanda petik.
4. Jalankan codenya di terminal menggunakan perintah python Ai_QualityAssurance.py ./src ./test.
5. Tunggu hingga prosesnya selesai dan perhatikan hasil outputnya di tampilan terminal tersebut yang nantinya laporan outputnya akan menjadi output file Json.
